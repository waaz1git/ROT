CORS: fal.ai allows browser calls. Replicate, Runway and Luma may block cross-origin requests — use the included Cloudflare Worker proxy or run locally with a proxy.
export default {
  async fetch(req, env) {
    const url = new URL(req.url);
    const map = {
      "/fal": "https://fal.run",
      "/replicate": "https://api.replicate.com",
      "/runway": "https://api.dev.runwayml.com",
      "/luma": "https://api.lumalabs.ai"
    };
    const key = Object.keys(map).find(k => url.pathname.startsWith(k));
    if (!key) return new Response("unknown target", {status:404});
    const target = map[key] + url.pathname.slice(key.length) + url.search;
    const headers = new Headers(req.headers);
    headers.set("origin", "https://rot.local");
    const r = await fetch(target, {method:req.method, headers, body:req.body});
    const out = new Headers(r.headers);
    out.set("access-control-allow-origin", "*");
    out.set("access-control-expose-headers", "*");
    return new Response(r.body, {status:r.status, headers:out});
  }
}

SAFETY PROTOCOL / READ ONCE
⚠

THIS THING
FLASHES.

ROT is a distortion instrument. It intentionally produces rapid flashing, high-contrast strobing, flicker, chromatic aberration and moving patterns. That is the point.

  • If you have photosensitive epilepsy or are prone to seizures, do not use the full-effect mode.
  • Stop immediately if you feel dizzy, nauseated, disoriented or unwell.
  • Safe mode caps the worst strobe effects. It is still intense, just less violent.
  • Sound is off by default. You can enable a low ambient drone in Setup.
By entering you confirm you have read this warning. You can reopen it any time from Setup → Motion & safety.
